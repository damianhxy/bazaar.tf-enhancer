#Bazaar.tf-Enhancer
====================

Evaluates the value of auction items and offers

This script automatically sums up the value of items on [bazaar.tf](http://bazaar.tf)'s auctions

Features:
* Value summation
* Highlighting of retracted offers
* Highlighting of unpriced items
* Better fraction handling than bazaar
* Item counter
* Automatic updating of currency prices
* Highlighting of unpriced and parted items
* Customizable
